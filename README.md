# Running Locally

Clone the repository

```bash
git clone https://github.com/Tanofxp/danielmatalone.dev.git
```

Go to the project

```bash
cd danielmatalone.dev
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
